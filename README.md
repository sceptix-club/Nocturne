<!-- Installation -->

### :running: Build Instructions

Clone the project

```bash
  git clone https://github.com/sceptix-club/Nocturne.git
```

Go to the project directory

```bash
  cd Nocturne
```
Build

```bash
  make clean && make
```
Run
```
./game
```
